# MyCoin Educational Blockchain

**MyCoin** is a fully educational hybrid Proof-of-Work blockchain written in Java.

It was created to help developers and students understand how a real blockchain works by combining:

- Classic double SHA-256 Proof-of-Work
- A unique combinatorial “City Distance” puzzle
- UTXO transaction model
- Simple P2P networking
- File-based persistence

> **Important**: MyCoin has **no monetary value**. It is not a real cryptocurrency and is intended only for learning and experimentation.

### Yorkshire Cities used in the puzzle
`bradford` · `mirfield` · `leeds` · `dewsbury` · `huddersfield` · `shipley`
